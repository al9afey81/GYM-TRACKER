# GYM TRACKER

متتبع رياضي عربي باتجاه RTL، يعتمد ملف GYM-TRACKER-v2.html المرفق باسم `index.html`، مع الصورة الأصلية المضمنة والثيم الأسود والذهبي. موقع ثابت دون بناء أو خادم تطبيق.

## الوظائف والحفظ

- اعتماد الأيام بالتسلسل مع التحقق من الحديد والكارديو والمدة والتاريخ.
- قفل الأيام المعتمدة، وأرشفة الأسبوع بعد اليوم السابع وفتح الأسبوع التالي تلقائيًا.
- تسجيل الكارديو الإضافي دون تقديم الجدول.
- الاحتفاظ بمفتاح التخزين الأصلي `gymtracker-v1` وبياناته. البيانات محلية للمتصفح وعنوان الموقع؛ لا تنتقل تلقائيًا بين الأجهزة أو من ملف محلي إلى GitHub Pages.
- عند فشل التخزين تبقى العملية غير معتمدة ويظل النموذج متاحًا لإعادة المحاولة.

## الاختبار

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm test
```

تختبر المجموعة الحفظ بعد إعادة التحميل، التحقق من الإدخال، منع تكرار تاريخ اليوم داخل الأسبوع، الكارديو الإضافي، إغلاق أسبوعين متتاليين وفتح الثالث، تحميل البيانات القديمة وفشل التخزين وإعادة المحاولة. تعمل على Chromium وWebKit بمحاكاة iPhone 13. محاكاة WebKit لا تغني عن تجربة Safari على آيفون فعلي.

للتشغيل محليًا: `python3 -m http.server 4173` ثم افتح `http://localhost:4173`.

## GitHub Pages بعد مراجعة PR ودمجه

1. في المستودع، افتح Settings → Pages واختر GitHub Actions كمصدر للنشر.
2. بعد دمج PR في `main` ونجاح اختبارات Test tracker، شغّل Publish GitHub Pages يدويًا من تبويب Actions على فرع `main`.
3. الرابط المتوقع: https://al9afey81.github.io/GYM-TRACKER/

النشر يدوي ومقيد بفرع `main`؛ فتح PR أو دفع فرع المراجعة لا ينشر الموقع. يُرفع `index.html` و`.nojekyll` فقط.
