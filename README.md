# GYM TRACKER

متتبع رياضي عربي باتجاه RTL، يعتمد ملف GYM-TRACKER-v2.html المرفق باسم `index.html`، مع الصورة الأصلية المضمنة والثيم الأسود والذهبي. موقع ثابت دون بناء أو خادم تطبيق.

## الوظائف والحفظ

- اعتماد أي يوم من الأيام السبعة بأي ترتيب، مع التحقق من الحديد في أيامه والتاريخ عند الاعتماد الأول. الكارديو اختياري في جميع الأيام؛ لا تُطلب مدته إلا عند تسجيل إنجازه، ويمكن اعتماد يوم الراحة دون حديد أو كارديو.
- تحرير الأيام المعتمدة عبر القلم، في الأسبوع الحالي والأسابيع السابقة. يمكن تعديل التاريخ وحالتي إنجاز الحديد والكارديو ونوعه ومدته؛ تُغلق تفاصيل اليوم بعد نجاح الحفظ.
- يظهر زر «إنهاء الأسبوع والانتقال للأسبوع التالي» بعد اعتماد وإنجاز أيام الحديد الخمسة، دون اشتراط يومي الراحة أو الكارديو. الضغط عليه يحفظ الأسبوع بعلامة صح خضراء ويفتح التالي مرة واحدة؛ تعديل أسبوع سابق لا ينشئ أسبوعًا جديدًا.
- الاعتماد منفصل عن الإنجاز: يبقى اليوم معتمدًا عند تعديل حالات الإنجاز، وتتحدث إحصائيات الحديد وعدد أيام الكارديو ودقائقه فورًا. لا تُحتسب دقائق الكارديو غير المنجز، ويظل الكارديو الإضافي محسوبًا.
- بيانات النسخة القديمة التي لا تحتوي حالة الكارديو تُقرأ باعتبارها منجزة، دون إعادة كتابة البيانات عند فتح الصفحة.
- تسجيل الكارديو الإضافي دون تقديم الجدول.
- الاحتفاظ بمفتاح التخزين الأصلي `gymtracker-v1` وبياناته. البيانات محلية للمتصفح وعنوان الموقع؛ لا تنتقل تلقائيًا بين الأجهزة أو من ملف محلي إلى GitHub Pages.
- عند فشل التخزين تبقى العملية غير معتمدة ويظل النموذج متاحًا لإعادة المحاولة.

## الاختبار

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm test
```

تختبر المجموعة الحفظ بعد إعادة التحميل، التحقق من الإدخال، منع تكرار تاريخ اليوم داخل الأسبوع، الكارديو الإضافي، اعتماد الأيام بترتيب غير متسلسل، إغلاق أسبوعين متتاليين وفتح الثالث، تعديل الأيام الحالية والسابقة وإحصائياتها، تحميل البيانات القديمة وفشل التخزين وإعادة المحاولة. تعمل على Chromium وWebKit بمحاكاة iPhone 13. محاكاة WebKit لا تغني عن تجربة Safari على آيفون فعلي.

للتشغيل محليًا: `python3 -m http.server 4173` ثم افتح `http://localhost:4173`.

## GitHub Pages بعد مراجعة PR ودمجه

1. في المستودع، افتح Settings → Pages واختر GitHub Actions كمصدر للنشر.
2. بعد دمج PR في `main` ونجاح اختبارات Test tracker، شغّل Publish GitHub Pages يدويًا من تبويب Actions على فرع `main`.
3. الرابط المتوقع: https://al9afey81.github.io/GYM-TRACKER/

النشر يدوي ومقيد بفرع `main`؛ فتح PR أو دفع فرع المراجعة لا ينشر الموقع. يُرفع `index.html` و`.nojekyll` فقط.
